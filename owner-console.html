M4 K4: a game type is the shared FaultDisputeGame implementation plus the arguments the factory stores for it - the absolute prestate among them (docs/proof-plan.md, K4). The defaults are Finchain Sepolia's: game type 8 (CANNON_KONA), the deployed implementation, the Finchain-embedding kona prestate of K2, the MIPS64 VM, the anchor state registry and the permissionless DelayedWETH. make k4-readiness prints the same arguments and calldata for comparison. This does not change the respected game type.
